软件公司界面接口交付版：锁成品V17 + 泵系统V13
=================================================

请先阅读：01_对接说明/软件公司界面接口交付说明.md

本包的两套应用都已调整为：
1. 首页“方案效能评估”；
2. 第二页“UTA模型训练”；
3. 删除顶部产品版本大标题；
4. 评价首页优先展示效能、贡献、曲线和解释；
5. 泵的物理可行性与耦合保留为辅助折叠信息。

锁V17和泵系统V13的Python算法、接口、状态及模型格式均未改动。
当前包仅含演示Excel，不含甲方真实数据、专家State或正式冻结模型。
最终集中软件上线前，必须分别换入甲方导出的锁V17和泵系统V13冻结模型。

开发机安装依赖：进入02或03目录后执行 python -m pip install -r requirements.txt
运行锁演示：进入02目录后执行 start_lock_demo.bat
运行泵演示：进入03目录后执行 start_pump_demo.bat
