# 锁成品 V17 技术说明与维护手册

## 1. 模型目标

V17 学习的是选定基准附近的单向退化效能与复用边界，不是全空间绝对效能，也不是物理可行性模型。

基准方案`b`固定为 100 分。对属性`j`定义退化量：

```text
越大越好：d_j = max(0, (b_j - x_j) / (b_j - generation_min_j))
越小越好：d_j = max(0, (x_j - b_j) / (generation_max_j - b_j))
区间型：按低侧或高侧分别使用基准到对应生成边界的距离
```

学习坐标为：

```text
goodness_j = 1 - clamp(d_j, 0, 1)
```

因此不同单位和数量级在进入学习器前都归一到 0 至 1。优于基准时`d_j=0`，不额外加分。

## 2. 单项边界算法

每个退化维度单独维护：

- `accepted_d`：已确认仍可复用的最大退化；
- `rejected_d`：已确认不可复用的最小退化；
- `limit_d`：二者中点；
- `status`：pending、probing、learned、full_range_reusable 或 unresolved。

初始探针比例为：

```text
0.10, 0.22, 0.38, 0.58, 0.78, 1.00
```

形成正反夹逼后使用二分。默认归一化容差为 0.035，即基准到最差生成边界距离的 3.5%。整数属性和显示精度会经过可见步长检查，避免连续生成舍入后相同的题。

单项阶段不直接识别属性权重。它提供每个属性的独立复用硬边界，并为多属性生成确定有意义的退化尺度。

为避免“可退化空间很窄的属性只挤在曲线开头、空间很宽的属性占满整条曲线”，V17 为每个属性建立自适应曲线坐标。设单项已学习边界比例为`s_j`，其位置统一映射到有效曲线坐标`0.75`：

```text
d <= s_j: z = 0.75 * d / s_j
d >  s_j: z = 0.75 + 0.25 * (d - s_j) / (1 - s_j)
```

LP-UTA在`z`上学习，界面和工程边界仍用原始`d`与实际单位表达。这样宽、窄容忍属性都能学到足够的边际形状。

## 3. 多属性生成器

第二阶段从已学单项边界的已确认可复用侧构造候选：

- 每个方案改变 2 或 3 个退化维度；
- 不生成优于基准的属性；
- 每个维度的硬上限使用`accepted_d`，不使用包含未知区间的`limit_d`；
- 连续属性默认取`accepted_d`的 24%、42%、60%、78% 或 94%，并对舍入后的实际工程值再次校验；
- 任一维度不得越过已确认单项可复用上限；多项标签只学习单项均可接受时的叠加效应；
- 前期保证所有属性最低覆盖，之后按已确认可退化宽度的平方根自适应增加宽容忍属性题量；
- 采样频率只影响问题分配，不进入UTA权重；
- 记录组合签名，降低重复；
- 用 BT 概率接近 0.5 的程度优先选择信息量较高的 A/B；
- 兼顾证据稀缺属性和组合覆盖。

单项边界中点`limit_d`仍用于未知方案边界说明，但不能作为第二阶段生成上限，因为中点包含尚未被专家明确接受的一侧。离散或整数属性若安全余量经舍入后没有可见变化，允许回到最后一个明确接受的离散值，但仍不得越界。

专家提供三类信号：A 整体复用标签、B 整体复用标签、A/B 偏好与强度。

## 4. BT 与 LP-UTA

V17 复用 V15 中已经验证的`OnlineBTModel`与`LPUTAModel`，但输入不是原始工程量，而是基准封顶的无量纲 goodness。

BT 用于：

- 在线学习粗粒度属性权重；
- 估计 A 优于 B 的概率；
- 为主动选题寻找当前最难区分的方案。

LP-UTA 用于最终可解释评分：

```text
U(x) = 100 - sum_j Loss_j(z_j)
```

约束包括：

- 总权重归一；
- 属性边际单调；
- Excel 边际规律对应的凸凹形状约束；
- 专家 A/B 次序约束；
- 允许最小松弛处理少量误判；
- 固定哈希训练/测试划分；
- 交叉验证、整方案留出和确定性 Bootstrap 稳健模型。

设计顺序 1、2、3 只作为初期先验。有效偏好增加后，UTA 由专家判断修正权重，不会把设计顺序永远当作固定分数。

## 5. 综合复用分界

多属性阶段的复用标签按当前 UTA 分数投影到一维，寻找加权分类正确率最高的阈值。若“不可复用最高分”低于“可复用最低分”，阈值取二者中点。

整机判断采用双层门控：

1. 任一属性明确超过单项极限，整机不建议直接复用；
2. 单项均未越界，但总分低于综合分界，多项叠加导致不建议复用；
3. 单项和综合均通过，判为可以复用；
4. 边界或阈值证据不足，输出仍需专家判断。

## 6. 一致性与复核

LP-UTA 的 M1 检查判断集合能否在零松弛下满足，作为研究诊断；M1失败不会单独阻止完成。M2 使用最小松弛拟合，M3定位最小冲突证据集；明确冲突进入必须复核，高容忍异常进入建议复核。复核项保存原A/B、原判断和明确证据ID。重新判断只替换对应证据，撤回一条只改变该证据状态，不批量删除其他判断。

完成状态不是只看一个正确率，而是同时检查：

- 单项边界完成；
- 训练对数量；
- 测试集正确率；
- 交叉验证；
- 整方案留出；
- 判断一致度；
- UTA有效区段覆盖和可靠覆盖；
- 综合分界类别与准确率；
- 定期盲重复题的稳定性；
- 未处理的必须复核项。

最低有效偏好数为`max(20, 2 × 属性数)`。标准完成要求测试、交叉验证和整方案留出的保守正确率不低于80%，判断一致度不低于80%，有效区段覆盖不低于80%，可靠覆盖不低于60%，综合分界正确率不低于80%，且没有必须复核项；达到更高指标时显示高置信完成。

## 7. 多评价基准迁移

专家只围绕Excel第一份主基准训练。较低评价基准采用逐属性归一化曲线形状迁移：按新基准到同一生成差端重新计算原始退化比例`d'`，再输入主模型已学习的自适应UTA曲线。

```text
Loss'_j(x | b'_j) = Loss_j(z_j(d'_j(x)))
U_new(x) = max(0, 100 - sum_j Loss'_j)
```

因此新基准严格100分，优于新基准的属性截断为零扣分，不补偿其他属性。单项极限保持原`limit_d`的相对位置并映射为新工程值；综合复用分界保持同一总损失预算。主曲线证据范围外标记形状保持外推，新基准优于主基准时不静默迁移。逐属性纵向重锚和总分整体平移只作为诊断对照，不参与用户结论。

## 8. 在线与冻结共用逻辑

`lock_utility_model.evaluate_migrated_reuse_model`是在线应用和冻结运行时的共同评分入口，防止两个版本逐渐产生口径差异。

冻结模型只保留：

- 属性 schema、训练主基准和全部评价基准；
- BT 权重；
- UTA 分段数与增量；
- 数据最小化单项边界；
- 数据最小化综合分界；
- 汇总训练指标和版本摘要。

逐次观测、标签明细、自由文本和 State 不进入冻结包。测试要求在线和冻结输出完整字典等值。

## 9. 状态结构

每个项目只维护一个主训练 session，评价基准不另建 session。主要字段：

```text
single_boundaries
single_order
multi_attribute_counts
multi_signatures
interactions
reuse_evidence
preference_evidence
review_items
uta_segments
bt_weights / bt_model
uta_increments / uta_model
combined_reuse_threshold
active_pair
unknown_evaluations
```

State 使用`lock_product_degradation_v17`契约和`lock_v17_`学习指纹，不读取或迁移 V15 State。

学习指纹只依赖属性结构和第一份训练主基准，不依赖历史样本、耦合表或第二行以后的评价基准。新增或调整较低评价基准不会丢失训练State，但必须重新导出冻结模型。

## 10. 维护入口

常调参数：

| 参数 | 文件 | 当前值 | 影响 |
|---|---|---:|---|
| `PROBE_LEVELS` | `lock_v17_app.py` | 6级 | 单项初始搜索速度 |
| `BOUNDARY_TOLERANCE` | `lock_v17_app.py` | 0.035 | 单项边界精度与点击次数 |
| `DEFAULT_UTA_SEGMENTS` | `preference_models.py` | 3 | 曲线灵活度与所需判断数 |
| 综合分界最少证据 | `fit_combined_reuse_threshold` | 8 | 分界从初步到已学得 |
| 自适应边界坐标 | `lock_utility_model.py` | 0.75 | 单项极限在UTA曲线中的统一位置 |
| 完成验证阈值 | `learning_completion` | 0.80 | 是否允许结束训练 |

修改完成判据时，必须同步界面解释、测试和冻结 training summary，不能只改文案。

## 11. 回归测试

```powershell
python -m unittest -v test_lock_v17.py
python audit_lock_v17.py --multi-rounds 55 --output V17_algorithm_audit_20260827.json
python portable_launcher.py --validate-only --workbook data\product_v17_lock_demo.xlsx
```

自动审计至少检查：

- 单项阶段每题只变一项；
- 所有属性恢复基准后轮换；
- 多属性每侧不超过三项；
- 组合重复率和属性覆盖；
- 宽容忍属性在最低覆盖后获得更多问题；
- 必须复核阻止完成且重判只替换目标证据；
- 基准严格 100；
- 较低基准曲线迁移不放宽到生成端点且更优属性不补偿；
- UTA 与综合分界形成；
- 未知方案输出完整；
- 在线与冻结等值；
- 冻结包无原始训练记录。

## 12. 已知边界

1. V17 只在选定基准定义的单向退化语义下有效。
2. 较低评价基准可以迁移；换成优于主基准、改变属性集合、单位、偏好方向、生成范围或主基准时需要校准或重新训练。
3. 专家若把“物理做不到”和“效能不可接受”混为一谈，会污染复用边界。
4. 单项边界能回答独立退化极限，但属性权重必须依赖第二阶段 A/B 权衡。
5. 对生成范围外的极端输入，UTA 分数会在最差端饱和，但属性退化百分比仍会显示超界程度。
6. 本模型不应单独用于安全认证、适航结论或制造可行性判断。
