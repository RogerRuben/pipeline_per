# 系统级效能评价 V13 用户操作说明

## 1. 软件在做什么

软件让专家比较成品方案对液压系统的效能贡献。它先把当前系统要求附近学准确，再自动转到其他规格区域补齐曲线，最终得到可在不同流量任务间复用的全域效能模型。

专家不需要自己选择“现在学高流量还是低流量”。页面顶部会说明当前区域和本轮校准工况。

## 2. 每轮怎样判断

1. 先看当前学习区域，例如“高流量规格”或“低流量规格”。本轮 A/B 流量都在这个范围内。
2. 看黄色主动变化、蓝色耦合联动和绿色其他差异，优先判断真正不同的属性。
3. 历史实物自动视为已验证可行，不需要再次判断物理可行性。
4. 对生成方案选择“可以实现”“不能实现”或“暂时看不准”。
5. 两边都能实现时，再判断哪个方案在页面所示校准工况下系统效能更好。
6. 同时变化太多、差异太小或信息不足时，选择“信息不足，无法比较”并选原因，不要勉强猜。

区域切换后，A 也会换成本区域方案，不会继续拿上一规格的胜者压着新区域比较。

## 3. 可行、不可行和低效率

- `不能实现`：真实物理上做不出来，例如压力和流量不变却把重量减到当前技术无法达到。
- `能做，但偏保守/效率低`：可以制造，只是不先进。它不会被学成不可行。
- `能做，而且是可实现新前沿`：专家确认这是一项新的可实现能力。
- `能做，但现有耦合知识没覆盖`：提醒后续补充知识，不会形成负例。

## 4. 为什么会切换学习区域

高流量任务附近学完后，软件会显示“当前任务附近已就绪，正在补齐其他规格区域”，然后把下一组 A/B 一起移到其他流量区间。此时应按页面给出的新校准工况判断，而不是继续按最初的高流量要求判断。

这样一次专家训练可以同时学到高、中、低规格曲线。将来切换真实系统任务时，不需要因为要求从高规格改为低规格而重新完成整套点击。

## 5. 何时结束

页面的完成状态同时检查：各代表规格区域、共享有效比较、保守验证正确率、判断一致性、全域 UTA 区段覆盖和必须复核项。

M1 严格一致性只作诊断，不会因为少量可解释冲突永久阻止模型完成。区域卡片全部完成且总状态显示“全域多工况效能模型学习完成”后，再冻结正式模型。

## 6. 复核怎样做

出现必须复核时，页面会显示具体原 A/B、变化属性、原判断和记录编号。点击“重新打开原 A/B 并判断”，新判断只替换对应证据，不会误删其他复核项。

V13 的复核编号在所有系统任务和规格区域中全局唯一。若从 V12 迁移的记录存在重号，软件会在首次启动时自动改号；页面显示的新编号就是后续操作依据，不需要凭记忆查找原方案。

## 7. 评价未知方案

1. 点击顶部“未知方案评价”。
2. 输入成品属性；公式派生属性按配置自动回算时以回算值为准。
3. 点击“开始评价”。
4. 查看当前任务综合效能、要求是否满足、任务适配、成品固有性能和物理可行性。
5. 查看六属性曲线上的当前落点、同一方案在代表工况下的表现、区域模型敏感性和流量-重量历史位置。

未知方案评价始终按当前选择的真实系统任务计算，不会拿训练用的临时校准工况当正式要求。

## 8. 可视化怎样理解

- `系统属性 UTA`：压力、流量、重量在任务要求下的边际曲线。
- `成品属性 UTA`：功率、工作时间、脉冲压力等固有性能曲线。
- `同一方案在代表性系统任务下的表现`：检查模型能否跨高低规格使用。
- `区域模型敏感性`：邻近区域模型对当前分数的差异，不是统计置信区间。
- `流量-重量历史分布`：历史实物、区域任务锚点和当前未知方案的位置。
- `耦合可实现前沿`：绿色为明确可行侧，灰色为尚未辨清，红色为现有证据支持的不可行侧。

## 9. 数据保密

完整档案含逐次判断和自由文字，应留在甲方受控电脑。交给统一软件或推荐模块时，使用“冻结并导出模型”生成的隐私冻结包；冻结包不包含完整点击日志和自由文本。

## 10. 从 V12 继续判断

1. 先关闭 V12 黑色运行窗口，并保留原 V12 文件夹作为备份。
2. 完整解压 V13 轻量包，复制兼容的整个 `runtime` 文件夹。
3. 把原 V12 文件夹中的整个 `userdata` 复制到 V13 根目录，选择合并并覆盖 V13 的空白说明文件。
4. 先运行 `verify_system_v13.bat`，再运行 `start_system_v13.bat`。
5. 选择与 V12 相同的正式 Excel。首次打开会显示“V12判断已迁移到系统级V13”。

迁移保留专家判断、可行性证据、区域进度和未处理复核，不要求重新训练。不要把 V11 或更早版本的 State 放入 V13。
