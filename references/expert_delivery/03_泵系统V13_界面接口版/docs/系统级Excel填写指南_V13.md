# 系统级效能评价 V13 Excel 填写指南

V13 继续使用通用 `system_excel_v10` 表结构，不要求增加“高流量区”“低流量区”工作表。代表规格区域由软件根据映射、历史样本、生成范围和当前系统要求自动发现。

## 1. 必需工作表

- `属性配置`：成品属性、单位、精度、生成范围、偏好方向和设计顺序。
- `方案数据`：历史已制造成品；每一行自动作为物理可行硬锚点，但不自动代表高效能。
- `耦合关系`：成品内部有向关系和约束模式。
- `系统属性配置`：系统侧属性定义。
- `成品到系统映射`：成品属性如何映射到系统属性及进入哪个通道。
- `系统任务要求`：真实任务要求、评分尺度和硬性策略。
- `派生属性公式`：可选，配置功率等通用公式。

## 2. 泵六属性示例

演示表包含压力、流量、重量、额定功率、工作时间和脉冲压力。名称和属性 ID 不是代码常量，可换成其他名称；程序依靠映射与要求类型识别角色。

- 压力：成品偏好可填 `interval`，系统要求通常填 `target`。
- 流量：成品偏好填 `higher`，系统要求通常填 `at_least`。
- 重量：成品偏好填 `lower`，系统有预算时填 `at_most`。
- 功率、工作时间、脉冲压力：按专家确认的方向进入成品性能贡献。

## 3. V13 怎样自动识别主规格

软件在直接系统属性中寻找“正值跨度最大且要求类型为下限型或相对越大越好”的属性。泵表中流量横跨约 1 到 70，通常会自动成为主规格轴。

按生成范围和历史范围的比值自动分区：

- 跨度比小于 2：1 个区域；
- 2 到 5：2 个区域；
- 5 到 20：3 个区域；
- 20 及以上：4 个基础区域；
- 当前真实任务锚点若与基础中心明显不同，可加入为额外区域，总数最多 5 个。

正值大跨度按对数尺度放置中心和边界，因此 1 到 70 不会被线性尺度挤在低端。

## 4. 系统要求怎么填

- `target`：要求点最好，两侧扣分，例如压力。
- `at_least`：达到下限为 100 分参考，继续提高可按配置超过 100 分，例如流量。
- `at_most`：达到上限为 100 分参考，继续降低可按配置超过 100 分，例如重量预算。
- `within_range`：区间内满足，区间外连续扣分。
- `relative_higher`、`relative_lower`：没有绝对要求时只作相对比较。

训练区域切换只会在内存中生成校准任务，不修改这里填写的真实任务。

## 5. 80 分距离怎么填

填“属性值偏离要求多少时应为 80 分”，单位与系统属性一致，不是填写 80 分对应的绝对属性值。

例如流量下限为 70，希望 63 对应 80 分，则下偏 80 分距离填 7。留空时软件暂按要求值绝对值的 10% 自动计算并警告；正式项目建议由专家明确。

## 6. 重量预算的区域缩放

高低流量产品的合理重量预算通常不同。V13 用历史样本中主规格与上限型预算属性的稳健对数斜率，自动估计缩放指数，并限制在 0 到 1.5。区域校准时重量预算按该指数随流量中心缩放。

这只是训练校准工况，不改变真实系统任务的重量预算；如果历史数据太少或关系不稳定，系统使用保守默认指数并依赖专家判断修正模型。

## 7. 耦合关系与公式

- `minimum_frontier`：上游能力增大时，目标属性存在随之提高的最低可实现前沿，常用于流量或压力到重量。
- `maximum_frontier`：目标过高的一侧不可实现。
- `hard_band`：上下两侧都可能不可行。
- `expected_trend`：偏离只是工程上不典型，不直接判不可行。

公式使用属性 ID 和白名单数学运算，不限定“压力乘流量除常数”。例如：

```text
pump_pressure * pump_flow / 60 / efficiency
sqrt(area * load) + offset
max(power_a, power_b)
```

## 8. 填表检查

1. 属性 ID 唯一，所有工作表引用一致。
2. 历史样本尽量包含主要规格层级；即使样本少，生成范围也应覆盖计划评价的全域。
3. 生成范围必须包含历史样本，且不能把物理上完全无意义的区域放得过宽。
4. 成品到系统映射的单位和系数正确，同一属性不要在两个效能通道重复计分。
5. 压力等目标型属性必须给合理要求点和左右尺度。
6. 流量、重量跨度很大时保留正值；零或负值会使自动对数分区退化为保守处理。
7. 公式目标属性不要再由生成器任意扰动，应在候选完成后统一回算。
