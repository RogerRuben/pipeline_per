# 系统级 V13 冻结模型调用与迁移说明

## 1. 冻结包包含什么

专家训练完成后点击“冻结并导出模型”，得到 `system_effectiveness_model_*.zip`。

包格式为 `system-effectiveness-frozen-runtime-package-13.0`，模型格式为 `system-effectiveness-frozen-model-13.0`。包内包含输入字段、系统映射、公式校准、共享 UTA、区域 UTA、区域校准上下文、任务要求、物理模型及 SHA-256 摘要，不包含完整专家 A/B 点击和自由文本。

## 2. Python 调用

解压冻结包，在包根目录运行：

```python
from frozen_system_model import FrozenSystemRuntime

runtime = FrozenSystemRuntime("model/frozen_system_model.json")

result = runtime.evaluate(
    {
        "pump_pressure": 21.0,
        "pump_flow": 45.0,
        "pump_weight": 22.0,
        "rated_power": 18.0,
        "working_time": 1200.0,
        "pulse_pressure": 31.0,
    },
    task_id="HYD-HIGH-001",
)

print(result["system_assessment"]["decision_score"])
print(result["system_assessment"]["task_transfer"])
```

字段名和任务 ID 必须读取冻结包中的模型契约，不要把示例字段写死到统一软件。

## 3. 运行时更换要求

同一系统属性结构下，可在调用时传入要求覆盖并立即重算，不重新训练：

```python
result = runtime.evaluate(
    params,
    task_id="HYD-HIGH-001",
    requirement_overrides={
        "system_flow": {"minimum": 35.0},
        "system_weight_contribution": {"maximum": 18.0},
    },
)
```

运行时会根据新任务与各代表区域的距离，对邻近区域模型平滑插值；远离已学习区域时会降低迁移把握并明确标记外推。不得通过直接修改总分字段模拟新任务。

## 4. 统一软件应展示

- 最终决策效能和连续效能；
- 当前任务适配分与成品固有性能分；
- 是否满足每项系统要求、差距和贡献；
- 物理可行性与耦合依据；
- 当前任务所用区域模型、插值或外推方式及迁移把握；
- 主要加减分、公式回算和必要的曲线图。

生产界面不需要 A/B 训练和复核页面，但冻结包里的推理依赖源码必须作为整体保留。

## 5. 更新与回滚

新模型应整体替换，不拆分复制 JSON 节点。上线前校验格式版本、哈希、输入字段、任务列表，并用至少一个已知方案对比专家软件在线结果。保留上一版完整 ZIP 以便回滚。

V12 或更早冻结运行时不能加载 V13 冻结模型；冻结模型必须连同 V13 包内 `source` 整体调用。训练 State 方面，V13 明确支持 V12 自动迁移，但不接受 V11 及更早 State。

## 6. 联调验收

1. 在线与冻结运行时对同一输入、同一任务评分一致。
2. 运行时要求覆盖与在线任务切换结果一致。
3. 高低流量任务使用不同的邻近区域，但共享模型不被重新训练。
4. 历史精确方案的物理可行性为 100%。
5. 公式派生值、系统映射和评分账本一致。
6. 冻结包不含逐条专家点击和自由文本。

## 7. V12 训练 State 迁移

V13 沿用 `system_v12_pump_` 状态文件名前缀，仅用于找到同一 Excel 对应的 V12 状态。首次加载时执行以下一次性迁移：

- `system_profile_version` 从 12 更新为 13；
- 从已保存的方案生成说明或 A/B 参数差异恢复主动设计变量；
- 将耦合联动和公式派生变化与主动变化分开记录；
- 按新口径重新统计可靠覆盖并重训共享/区域 UTA；
- 为跨任务、跨区域重号复核项分配全局唯一 ID；
- 保留原判断、原方案、可行性证据、复核状态和审计历史。

迁移只发生在复制到 V13 文件夹的 `userdata` 中。原 V12 文件夹应保留为只读备份，不要再让 V12 与 V13 共用同一个正在写入的目录。
