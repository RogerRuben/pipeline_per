# R6 本地开发包路径修复（2026-11-03）

## 已复现的原因

旧轻量包解压在仓库的深层目录后，NumPy OpenBLAS DLL 的完整路径达到 280 个字符。PowerShell 和扩展路径读取确认文件存在，SHA256 与清单相同；包内 CPython 3.8.10 使用普通路径时 `is_file()` 返回 false。实际运行旧 `CHECK_ENVIRONMENT.bat`，得到与用户报告完全相同的“开发包文件缺失或改变”错误。

上轮验收使用较短的临时路径，没有覆盖这次的深层解压路径。

## 修复范围

- 新交付文件为 `deliverables/CB6.7z`，包内根目录为 `CB6`。不再叠加两个长版本目录名。
- 五个 BAT 入口启动 Python 前检查根目录长度，超过 100 个 UTF-16 单元时明确提示整体移到 `C:\CB6` 或 `D:\CB6`。Python 校验入口执行同一限制。
- 完整性校验分别报告路径越界、文件缺失、文件校验不一致；没有忽略 DLL 或放宽 SHA 校验。
- 训练算法、数值依赖 DLL、冻结的软件引擎均保持原版。开发包清单和源码封印重新生成，并明确标记本地补丁 `r6-pathfix1-20261103`，基线为 `18baf0c63fd7b8b04f1b51a0d6ff5b56f5a92a08`。
