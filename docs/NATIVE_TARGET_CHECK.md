# Win7 SP1 x64 目标机验收

完整解压运行包，先确认包内 Python 3.8.10 可以在该机器加载，再双击 `TARGET_CHECK.bat`。脚本使用包内解释器，在用户目录建立新的隔离数据，实际启动本包原生 `product.exe`，不修改已有安装，也不自动上传报告。

自动演练覆盖：文件完整性、指定端口、三个服务、重复启动、V3 预测与三入口一致、Top10、保存方案、备份、子进程恢复、启动器被结束后的子进程清理、陈旧状态恢复、还原到新目录并重新启动、方案／规则／价格一致、SQLite 完整性和禁止覆盖已有数据。

结果保存为新目录中的 `target_report.json`。包内 Python 若不能启动，查看旁边 `.bootstrap.log` 和系统错误截图；EXE 启动失败时查看隔离 `userdata/logs`。常见原因包括系统补丁、VC/UCRT 运行库、端口占用和外部 Job 限制。请保留具体失败记录，由甲方 IT 处理，不关闭安全防护来通过验收。

自动检查后仍需实际浏览器操作：Portal、推荐、深度价格预测、字段修改、敏感性／情景／导出、运行管理中的单服务启停及重启、退出后无遗留进程。记录 OS／SP／位数、浏览器版本、包 SHA、端口配置和耗时。

当前原生引导器针对 Windows 6.1 x64，仅导入 Kernel32／User32，没有 PyInstaller 引导器；包内解释器和数值依赖仍有自身系统要求。程序继续使用 Windows Job 持有服务，并监视启动器父进程。Win7 不支持嵌套 Job，若在兼容性或受限 Job 环境中启动，需依据实际日志处理。

当前没有 Win7 实机验证记录；Windows 11 上通过不代表 Win7 已通过。脚本在非 Win7 主机明确记录 `not_a_win7_target_machine`，且不会自动把 `win7_validated` 设为 true。
