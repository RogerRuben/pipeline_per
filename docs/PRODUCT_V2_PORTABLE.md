# 价格AutoML V2、效能与推荐：离线成品包

本包自带Python3.8.10 x64、sklearn0.24.2、NumPy1.19.5、SciPy1.5.4、pandas1.3.5、Optuna3.6.0及其依赖。无需安装Python、pip或联网；所有启动入口使用包内相对路径。

## 只换表的用法

1. 将ZIP完整解压到可写目录，不要直接在压缩软件里运行。
2. 用处理好的成品表替换 `input/products.xlsx`，保留这个文件名。
3. 双击 `START.bat`。数据/配置改变时自动训练价格、构建效能和推荐，然后打开本地页面；未改变时直接启动已有结果。

包内保留10条记录、50属性的虚拟示例以及已构建的试用成品，首次不换表也可以直接试用。自己的数据须通过下述格式检查。也可以把CSV/XLSX拖到START.bat，或在命令行运行 `START.bat "D:\数据\成品表.xlsx"`。

`REBUILD.bat` 强制重建，`VERIFY.bat` 校验包内环境与文件。`CHECK_INPUT.bat` 只检查当前成品表，`TEST_COMPATIBILITY.bat` 检查控制台及表格兼容。训练进度、错误及运行环境自检保存在logs；每次构建写入新的outputs目录，旧构建保留。关闭服务请在启动窗口按Ctrl+C，停止三个包内服务。

2026-10-10新增保存版本入口：训练完成后双击`RUN_SAVED.bat`，只运行`state/latest.json`指向且模型摘要校验通过的版本。此入口跳过训练表读取、数据/训练配置指纹比较、AutoML和重新构建；修改或移走原始训练表也不会触发重训。没有完整保存版本或模型损坏时明确报错，要求主动训练，不自动重训兜底。运行端口仍从运行配置读取。

需要固定某一次版本时，使用该次`outputs/run_时间_编号/START_PROTOTYPE_WIN7.bat`。新版修正了该BAT路径中的反斜杠被Python解释为回车/制表符的问题；`RUN_SAVED.bat`会修复最近版本的这个启动脚本，模型文件保持原样。

训练结果包含`price/price_native_bundle.pkl`（成员、补全/编码/缩放、目标反变换和融合权重）、`effectiveness/effectiveness_bundle.json`、业务包、推荐工作区及配置/验证报告。它们是已拟合结果，重启加载后即可预测。迁移请保留完整交付目录及包内运行环境；单独复制一个outputs目录不能作为独立运行包。重训仍运行`REBUILD.bat`，结果写到新版本目录，旧版本保留。

## 成品表要求

- 建议将数据页命名为“成品数据”，无需放在第一张表。程序优先选择这个可见工作表，否则自动识别唯一匹配的双行成品表；多个候选会明确报错，隐藏工作表不参与选择。第1行每列为中文名，可带单位；第2行是唯一英文代号，以字母开头，仅含字母、数字、下划线；第3行起为记录。
- 建议前三列为“成品编号 / product_id”“成品名称 / product_name”“价格(万元) / price_wan”，其余为功能、性能、环境属性；属性数量可以变化。
- 至少10条具有有效正价格、配置不同的记录，价格须有变化。编号和名称不同而属性相同的记录仍算同一配置。更多有效真实记录才能支持可信精度判断。
- 数值保持数值，布尔可用有/无或0/1，枚举保持一致文字；空白及配置中的缺失符号交给折内补全。公式应先计算好并保存数值，图片、合并表头和.xls不支持。
- CSV支持UTF-8、GB18030、带BOM的UTF-16，自动识别逗号、分号、制表符及Excel的sep声明。若使用 `input/products.csv`，须移走products.xlsx，使input只有一个默认输入文件。

## R2控制台与表头兼容修复

R2统一使用普通日志，在应用入口和训练子进程中提前关闭Colorama初始化及终端探测。仅标准输出设备的错误可降级到 `logs/console_fallback_进程号.log`，数据、模型等实际文件权限错误继续明确报错，不会被吞掉。没有修改第三方库文件。

读表会忽略所有记录都没有内容的空白列，包括Excel/WPS留下的格式单元格；有真实数据的列绝不会因为表头空白而被丢掉。英文代号自动清理BOM、零宽字符和全角形式，保留大小写；清理后出现重复仍拒绝。普通标点和内部空格不被擅自改名。

`logs/input_diagnostics.json` 记录实际读取的工作表、表头物理坐标、原值、清理结果和忽略的空白列；真实错误会指出具体单元格。表头公式没有缓存值时会提示重新计算保存或粘贴为值。建议将R2完整解压到新目录，只复制自己的成品表，不必沿用之前手工修改的程序文件。

## 专家预设与字段变化

模板的“专家模型权重”“价格工程先验”“属性配置”“耦合关系”是可选专家表，沿用已实现V2的列格式。存在这些表时使用本次工作簿意见；普通双行表头也能运行，价格使用包内通用模型族预设，效能采用已有中文方向推断和样本经验范围。

工程成本公式全部属性匹配时增加工程成本及残差模型；如果某个成本属性不存在或变成枚举，停用整条工程公式并记录原因，剩余可用模型族的软先验按原比例归一化。专家硬性最低份额无法满足时明确失败。效能中已不存在的属性和耦合会排除并记录；未知方向仍保持中性。不会把虚拟成本公式部分拆开套用到其他字段。

每次输出的 `input_adaptation.json` 显示适配结果；`price/effective_config.json`、`price/weight_report.json`、`effectiveness/bootstrap_report.json` 显示实际设置和来源。所有前台属性使用中文，计算使用英文代号。

## 可调整设置

R3对不超过29组的微样本自动启用稳健训练：固定小候选组合、内外层分组留一、受限自由度岭回归及折内低维压缩，并检查融合权重敏感性。最低独立组数仍是10；质量提示中的30不阻止训练。详情见 `docs/PRICE_MICRO_SAMPLE_R3.md`，微样本控制在价格JSON的 `small_sample` 段；`TEST_MICRO_SAMPLE.bat` 可运行对应回归检查。

普通换数据不必改代码或配置。若需改变训练预算、候选模型、搜索范围、折数、种子档位、MAPE/R²目标及专家预算，编辑 `config/price_automl_v2.json`；成品名称、缺失符号和端口在 `config/portable.json`。配置变化会自动触发重建。默认训练总预算900秒，单次拟合90秒；不足时明确报错并保留缓存，可增加预算重试。

默认页面为 http://127.0.0.1:18791/ ，端口被占用时自动选择空闲端口，以控制台打印地址为准。系统只监听本机，按此包内成品工作区运行。

## 环境范围与结果解释

目标为64位Windows，采用兼容Win7的Python3.8路线。Win7应为SP1并具备Python要求的系统补丁和Universal C Runtime；包中包含Python发行版的VC运行DLL，系统补丁不能由复制应用文件替代。Python官方说明见 https://docs.python.org/3.8/using/windows.html 。交付报告记录实际测试主机，未进行Win7实机认证时不会声称已认证。

虚拟示例用于验证训练、导出、预测、效能、推荐和换表流程。微样本指标不能代表真实精度；专家预算约束开发OOF误差，不保证未来样本误差；效能权重、经验耦合和可行性仍是初版试用模型，预测区间尚未校准覆盖率。

包内依赖的许可证保留在 `runtime/python38/LICENSE.txt` 及各库的dist-info元数据目录。不要将库升级后直接混用旧模型。
