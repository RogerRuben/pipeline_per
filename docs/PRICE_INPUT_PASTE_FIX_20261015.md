价格属性英文代号误报修复（2026-10-15）

已复现：在原示例成品表中清空一个带示例评分的属性列，或把一个属性替换为合法的新英文代号，旧版都会给出“价格属性评分引用未知或不可用于训练的英文代号”。这混淆了字段合法性、示例预设及训练可用性。

本次处理：

1. 未修改的随包示例评分在内存中作为“示例预设”读取，仅对当前表内存在的属性生效；不修改磁盘上的配置文件。实际JSON评分、工作簿专家评分分别校验，工作簿优先，真实错误不会被当作示例忽略。
2. 成品表中存在但全空、只有缺失标记、文本或没有带价格观测的属性，不再被误报为“英文代号不存在”。仅有可用观测的属性参加训练；原始1—5分和未参与原因仍在报告、价格解释中保留。未把空列填成0。
3. 表头与评分引用统一清理复制带入的不可见格式字符、全角形式；评分中的大小写按本表唯一代号匹配。重复或冲突引用仍会明确报错。
4. 价格评分表支持“价格属性英文代号”等表头、调换列顺序、带“1—5”说明的评分列及中英双行表头。真实错误按原工作表、实际单元格定位，并给出相近代号。
5. 构建输出增加input_diagnostics.json；价格目录增加input_validation.json，异常时保存input_error_details.json。

使用：先关闭旧程序，把对应增量补丁解压覆盖到旧包根目录（assets和tools所在层），再重新运行原训练脚本。依赖、模型、数据库、样本及自定义JSON配置不在补丁中，不需要下载新wheel；之前的安装修复也一并包含。

price/input_validation.json列出本次使用的属性、未参与原因、忽略的示例预设和引用清理记录。price/price_attribute_scores.json保留各属性原始分值和评分记录。MAPE与R²质量门槛未下调。
