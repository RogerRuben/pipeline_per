# 按模块生成客户运行包

在开发包里双击 `③ 生成客户运行包.bat`，选择一种：

1. 完整系统。价格、效能、推荐和管理都在，和原来的客户包一样。
2. 仅价格预测。打开后是简易价格页，可预测、可进模型库。没有效能模型和推荐页，也不启动这两项服务。
3. 仅推荐系统。打开后是推荐页。价格和效能服务在后台参与推荐计算。没有单独的价格页、效能页和深度价格页。

直接回车等于完整系统。三种包都会生成运行目录、ZIP 和 `.sha256`。数据目录按产品和包类型分开，完整包仍用原来的目录。

改页面或源码后，在同一份开发包里重新编译，再生成客户包。不必为改字再做一份开发包。

本包复用完整冻结引擎。EXE 里仍有公共模块。价格包不附带效能模型文件。Windows 7 尚未实机验证。
