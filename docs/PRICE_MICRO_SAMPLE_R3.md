# R3：10条样本、40个属性的处理

## 当前设计的主要问题

R2能训练10×40，但通用训练策略不适合这么少的数据。10组先保留2组，开发集剩8组；外层两折每次训练4组，内层两折又缩为2组。此时监督式相关性筛选很容易选出偶然相关属性，`select_k=all`又允许全部高维进入低正则模型。再搜索多模型、多预处理及融合权重，会增加模型选择本身的过拟合。

R2的完整外层审核和固定保留集是正确的防泄漏措施；随机种子平均也能降低估计器随机性。但这些都不会增加独立样本，不能补足只有2条内层训练记录的问题。工程成本加任意高维残差还可能把错误先验用残差抵消，削弱解释的约束。

模型选择误差与选参偏差的讨论参考 [Cawley和Talbot，JMLR 2010](https://www.jmlr.org/papers/v11/cawley10a.html)。下述具体阈值是本项目的工程选择，不是论文证明的保证。

## 已实现的微样本流程

`small_sample.policy=auto` 时，独立组数不超过29自动采用微样本策略；更大的数据使用通用Optuna流程。`off`用于对照或明确选择原流程，`force`显式强制。运行最低独立组数仍为10；质量提示中的30仍只用于证据提示。

| 部分 | R2通用策略 | R3微样本策略 |
| --- | --- | --- |
| 10组下内层最少训练记录 | 2 | 6 |
| 验证 | 内外层两折与重复 | 固定保留2组；开发8组完整嵌套分组留一 |
| 候选 | 20次初筛、4次集成搜索及预处理组合 | 预先限定约9–13个配置，不做大范围随机搜索 |
| 特征处理 | 单变量监督筛选或全部属性 | 折内补全、常量过滤；默认2维无监督PCA或受控岭回归 |
| 岭回归 | 可搜索到接近无约束的惩罚 | 惩罚随维数调整，线性拟合自由度默认上限3，且不超过训练行数的一半 |
| 工程先验修正 | 可用全部属性拟合残差 | 只学偏置和总成本斜率两项，向零修正收缩，斜率修正限制在±50% |
| 融合 | 最多6个配置 | 默认最多4个配置，包含常量参考；优先保留有组增益的模型 |

保留全部原始输入属性，用户无需自己做PCA。数值、布尔、枚举仍在各训练折内分别处理；旧sklearn会丢弃全缺失列的问题由微样本保维补全处理。PCA不使用价格标签，所有学习仅在当前训练折内完成。[sklearn 0.24 PCA说明](https://scikit-learn.org/0.24/modules/decomposition.html#pca)、[岭回归说明](https://scikit-learn.org/0.24/modules/linear_model.html#ridge-regression-and-classification)。

候选含MAPE最优常量参考、不同收缩强度的岭回归、相对价格岭回归、低维贝叶斯岭回归、低维线性SVR和深度1的浅树对照。随机树默认平均4个固定种子；不挑选表现最好的种子。常量过滤只处理训练折，无标签特征筛选。

有明确成本公式时保留整个固定公式及低维校准。少量价格相关属性可由 `expert_features` 预先给出，也可来自已指定的成本属性；超过默认8项时不擅自按系数大小筛选，保留固定公式并停用自动学习子集。系数单位不同，大小不能直接比较。效能属性偏好权重不被当作价格系数。

## 权重与解释

候选须在开发OOF上优于常量参考，并有足够组胜率和MAPE增益；这是稳定性启发式，不能称为显著性检验。专家硬性最低份额仍须满足；和误差预算冲突时明确失败。

权重先按原有专家模式拟合，再检查删除一个开发OOF业务组时的敏感性。选择靠近删除均值的权重，但最终仍校验原始完整开发OOF的MAPE/R²预算及模型族硬界。删除敏感性没有重训其余OOF预测，所以只作权重稳定性诊断，不能冒充独立元模型验证；外层仍重跑整个候选和融合流程。

分组留一的单组R²不报告；R²基于汇集后的开发记录预测计算。只做一次留一协议时不把重复标准差写成0；数据仍不足，不保证置信区间。最终保留集冻结后只评估一次，再全量重训导出。

`sample_profile.json` 记录实际训练行数、原始维数、变换后维数和岭回归有效自由度；`weight_report.json` 记录预算和权重敏感性；`nested_audit.json`记录真实组边界。前台模型贡献、专家份额及工程成本分项继续可用。单个线性成员的自由度上限不等于整个集成的总自由度。

## 设置

在 `config/price_automl_v2.json` 的 `small_sample` 中调整 `ridge_alphas`（相对惩罚尺度）、`max_effective_df`、`latent_components`、`expert_features`、`calibration_strength`、`tree_seeds`、`max_members`、`minimum_group_win_fraction`、`minimum_mape_gain_pp`、`weight_jackknife`和`jackknife_blends`。

自动微样本模式不使用通用 `search.trials/ensemble_trials` 或可变预处理搜索空间；实际策略在报告里明确记录。专家误差预算仍使用 `ensemble.max_mape_delta_pp/max_r2_drop`，没有悄悄放宽。JSON未知字段和非法数值会拒绝。

效能仍为预设权重与工程耦合的初版；推荐仍为历史方案及模型评估的草稿。10条记录不能验证真实效能、因果关系或实际可行概率；价格微样本改进没有替代这些标注需求。

## 实验边界

对照预先固定10×40训练数据，外部256条独立合成记录只用于评估，不参与选参。包含正确工程先验、相关低维结构、明确价格特征指引、无信号噪声及错误工程先验。使用两个数据抽样种子；这和训练估计器的种子平均是两件事。sparse_known用于展示新结构先验接口，R2不支持该接口，其信息差异单独记录。

这些实验不构成真实业务准确率保证。仍保留低置信和证据不足标记；更多模型或更多随机种子不能替代真实独立数据。
