# R4.3 PATCH：小样本价格建模与联合预测

本补丁叠加到已有R4/R4.1/R4.2完整目录，复用Python3.8、numpy1.19.5、scipy1.5.4、sklearn0.24.2及Optuna3.6环境；没有新增依赖。不需要另装环境。开发机使用上述环境验证；没有在真实Windows7系统上执行。

## 使用

1. 关闭正在运行的服务，将ZIP内容解压覆盖到原目录，保留data、outputs、runtime。
2. 运行APPLY_R4_3_PATCH.bat启用默认纯数据训练配置。原精度目标、属性类型、缺失值配置、原始1—5分专家价格评分及旧模型保留，配置自动备份。
3. 先快速排查可用APPLY_R4_3_QUICK.bat，再运行RETRAIN.bat。正式训练用默认PATCH配置后RETRAIN。选择配置本身不会训练。
4. START.bat继续加载保存模型。只有成功训练并切换运行版本后，新特征与可信域才对预测生效。原流程的hard_gate配置保留；若其为true且审核不合格，保留旧运行版本和新诊断报告。

首次安装仍需完整离线包。本补丁不包含重复环境及训练缓存。补丁安装更新程序只刷新本补丁覆盖文件的完整性记录，不忽略其他文件损坏。

## 实质改动

- 重复CV：每次独立重复先计算误差，再汇总MAPE、R²及轮间标准差。对同一记录的多次预测平均后得到的成绩只作单独诊断，不能用它宣称验证达标。特征处理、筛选、选参、种子筛查和融合均限制在各外层训练数据内。
- 稳定性筛选：在训练折内重复抽取80%记录，统计原始属性被选频率，相关属性合并为候选组，降低36属性/16记录场景里一次偶然相关的影响。频率是诊断量，不保证错误发现率。筛选视图同时与全属性正则化、主成分等候选比较。
- 新增贝叶斯岭回归及ARD，使用训练数据学习收缩；与线性、非线性及核模型共同参与候选比较。专家1—5分是价格属性先验，经内部映射并调节先验强度，不是百分比，不强制变成价格或效能融合权重。默认关闭先验；EXPERT_COMPARE配置才开启比较。
- 融合：先淘汰风险损失超过最佳成员损失×4+0.05的极差候选（candidate_loss_ratio/slack可调），再按折外误差互补性加入成员，以重复CV波动、残差相关和权重扰动敏感性调节收缩。默认相对最强成员允许MAPE最多退化0.2个百分点、R²最多下降0.005，且整体风险必须改善；两个容忍量可设0。无益模型可以获得零权重，不设正权重下限。若没有合格组合，保留最佳单模型并明确ensemble_requirement_met=false，绝不凑数宣布联合预测达标。
- 校准也受不退化检查约束。融合的改善检查属于开发数据选择，是否能推广仍由完整外层审核判断。
- 每个外层训练集内部比较训练/验证误差，判断高方差或欠拟合：前者加强融合收缩和跨轮稳定性惩罚，后者先追加超参数搜索。此为启发式诊断，不使用外层审核成绩改变搜索策略。
- 修复搜索预算被前面模型吞完的问题：先让每个模型家族试一组参数，再做细网格与TPE；预热阶段默认最多占35%搜索时间（family_first/warm_start_fraction）。详细日志列出实际尝试过和未覆盖的模型。预算用尽记为正常剪枝，避免Optuna打印失败堆栈。
- 新增sample_influence.json、feature_stability.json及search_diagnostics.json。样本影响使用固定中性岭回归逐组删除做诊断，报告其他记录预测漂移；保留全部输入，不自动删异常样本。
- 保存历史属性联合距离可信域。预测保留原始价格，另输出模型分歧、外推属性、最近历史距离及保守排序价格。推荐预算、价格排序、保守性价比及候选生成使用同一保守价格，降低外推极低价造成的推荐偏差。其惩罚系数可设0；这是风险启发式，不是已校准概率/95%置信区间，也不是实际报价。

## 可调设置与速度

统一配置仍为config/price_automl_r4.json；config/r43_presets提供四套完整示例。APPLY操作会应用所选预设，手工调整应在APPLY之后进行。

| 设置 | 默认 | 快速诊断 |
|---|---:|---:|
| 内层折数×重复 | 4×2 | 4×1 |
| 外层折数×重复 | 4×2 | 4×1 |
| 每组搜索时间 | 90秒 | 30秒 |
| 总训练预算 | 1000秒 | 180秒 |
| 初次TPE次数 | 96 | 32 |
| 稳定性重采样 | 16 | 8 |
| 种子最大次数 | 5000 | 5000 |

种子数是上限：达到开发目标可早停，或受时间预算限制；不会因为几百次停滞且重选参次数用完而自动报TARGET_UNMET_AFTER_RESTART。完整外层审核后还需全量选择、拟合、诊断与保存，时间预算不包含不可中断的单个拟合和这些收尾操作；全局预算耗尽后最多另给120秒的最终拟合选择窗口，并在报告中标明审核是否完整。QUICK用于检查数据和流程，不等同正式精度审核。

主要调节入口：search.parameter_ranges、pipeline.select_k/select_fraction/stability_*、validation.*、ensemble.stability_penalty/regularization/max_mape_delta_pp/max_r2_drop/max_members、resources.*、trust_region.*。robust模式下minimum_weight/maximum_weight不施加正下限/小于1的上限；允许退化到单成员并报告数量未达要求。

16×36虚拟数据与无信号对照用于验证软件正确性；用户真实表未提供，补丁不声称已解决真实业务精度达标问题。
