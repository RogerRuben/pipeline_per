# R4.1：16条、36属性的价格训练排查与修复

适用原R4离线包。Python 3.8.10、sklearn 0.24.2、SciPy 1.5.4保持原环境；本机测试并非Win7实机。

## 已确认的问题

1. 原版16次外层审核，每次内层15次留一。32次选参及200次种子约需3480次拟合/轮；17轮（含全量开发）约59160次。若各轮跑满5000，约128万次拟合。不能把5000看成整个任务只拟合5000个模型。
2. 原版只在64、200、1000、5000次检查收益/打印进度。指标没达标也可能以development_improvement_stable停止；200/5000不意味着程序报错或质量达标。没有用户实际日志，不能断定该次运行是哪一种停止原因。
3. 核岭回归没有截距且未居中价格，正则化把价格（包括对数价格）压向零。这是模型实现缺陷。
4. 32次随机初搜分给11类模型，缺少系统的稀疏回归路径；岭回归只搜索0.01—10，遗漏高维噪声下的强收缩。expert_core只保留4—5分，3分属性可能也有重要价格信号。
5. 原版按单模型分数取前三组配置，可重复同类或把很多种子预算给慢模型；预处理测试矩阵重复计算；融合约束使用有限差分梯度。缓存把时间预算和进度设置也当作预测身份，增加预算后重复计算。

## 本次修复

- RBF核岭先对折内价格居中，推理加回训练均值；原已保存模型使用兼容回退，不改变其已有预测。
- 先系统筛查Ridge、相对误差加权Ridge、Lasso、ElasticNet和MAPE稀疏回归，再进行TPE。同时比较原价格/对数价格、专家先验及中性候选；默认岭收缩跨度0.001—1000。warm_start是额外的确定性筛查，anchor_trials是其后的TPE次数，均计入报告。
- all、expert_core与screened并行候选。screened仅在当前训练折用价格筛选原始属性，默认尝试3/5/8个，最多训练记录数的一半；不会在完整表上先筛特征再验证。1—5分仍作为价格重要性先验，不是百分比，不用于效能。
- 10—12组时内层留一；13组以上默认5折。外层微样本仍做完整留一，16条仍审核16次；所有选择均在外层训练部分重做。validation.inner_strategy=loo可恢复内层留一，适合进一步检查但耗时更高。
- 每64次检查收益，每5秒在拟合间打印阶段/模型/拟合数/耗时。仍保留5000上限，early_stop=false明确跑满（时间预算除外）。收益停滞且未达标先重新选参，之后停止会明确写targets_unmet_after_parameter_restart；不会标为通过。
- 按配置竞争力、模型差异和耗时分配种子；保留未扰动候选作为回退。缓存折内训练/测试变换；增加资源预算可复用同配置预测。融合使用批量计算与解析约束梯度；已满足两个目标的候选不会仅因加权总损失而被丢弃。

## 更新与运行

结束旧版仍在进行的训练。把R4.1修复ZIP解压到原R4目录，合并覆盖同名tools/services文件，再双击APPLY_R4_1_FIX.bat。脚本备份配置及包清单，合并新增默认设置并更新本次修复文件的校验值；环境和保存模型的原有校验保留。专家评分、业务目标、自定义范围、数据及已保存模型保留。之后运行RETRAIN.bat。文件更新不会改变已经运行中的Python进程，也不会替已保存模型重新训练。

START.bat继续只运行已保存模型；EXPORT.bat继续导出保存模型与环境。重训失败保留旧版本。完整包自带原环境与虚拟试用版本，首次换真实表后必须TRAIN/RETRAIN。

## 诊断与精度判断

每轮“内层开发MAPE/R²”用于选择该轮模型，不是该轮单条外层审核R²。最终应读取training_report.json.nested_cv_metrics及audit_complete；单条不计算R²。每条真实价格、外层预测、百分比误差在nested_audit.json。

input_diagnostics.json列出价格范围、缺失、常量、高基数类别及同属性异价冲突。后者还报告相同输入所能达到的MAPE下界与R²上界。nested/fold_XX/search_diagnostics.json与development/search_diagnostics.json列出每类模型实际拟合耗时、拟合数和重新选参次数。实际达标状态与停止原因分开保存。

测试采用预先固定的16条×36数值属性，包含相关属性、常量、噪声及价格重要性3分的有效属性；专家评分设合理/全中性/错误三种。另256条同分布虚拟数据从未参与选参和融合。测试用于比较实现及检查失效模式，不能保证真实16条表达到MAPE≤10%、R²≥0.9；尤其价格噪声、类别声明及缺少关键价格因素仍需要实际表诊断。

新增可调项：search.warm_start/restart_trials/max_restarts/seed_cost_ratio；pipeline.select_k；validation.inner_strategy/loo_inner_max_groups；seed_search.check_interval；resources.progress_interval_seconds。旧R4设置可直接加载。quality.hard_gate=true可拒绝审核未达标版本；默认未达标仍可导出试用，报告不会认证可用。
