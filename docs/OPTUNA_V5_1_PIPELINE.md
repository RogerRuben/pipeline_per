# V5.1：固定交叉验证、冻结权重与完整训练日志

更新于2026-10-27，沿用Python3.8.10、sklearn0.24.2及原离线环境。实体Win7尚未复测。

## 为什么修改

V5.0新增日志中的模型名表示本轮新增的成员，后面的成绩却属于重新优化权重后的整个集成。权重直接使用同一小块开发集价格求解，成员数增加后可能精确插值这几个价格。基础模型没有训练这些开发记录，并不能阻止融合层使用其标签过拟合。默认最后只报告跨划分复核，也不能约束前面的选择。

两个各有10%误差的预测向量`0.9*y`、`1.1*y`就可以通过各50%的份额取得零误差。这是旧权重求解能出现的真实数值，不代表单个Lasso完美，也不足以认定输入表泄漏。V5.1不人为增加误差或伪造R²上限；记录真实精度、预测明细及评估范围。

## 当前默认流程

1. 保留原V3搜索和原单划分参考，默认300轮；有匹配检查点时复用。它只提供起点及对照，原单划分分数不作为新增候选的接纳依据。
2. 根据输入分组和固定种子预先建立CV计划，不根据价格选择划分。默认最多4折，每条记录每次重复恰好留出一次；4—7条时自动降低折数，训练、验证各至少2条。相同输入整组隔离，无法合法划分时明确拒绝，不拆散组。
3. 将V3参数和固定权重在同一CV计划上完整评估，得到真正可比的CV基线。
4. 新增候选每次只修改一个模型族的参数；在全部固定折上重新拟合该族，复用其他族预测。先评估不依赖数据标签的保守正则化/浅树起点，再继续宽范围TPE搜索。合格候选替换该族原配置，不无上限堆积同族成员。
5. 默认`baseline_fixed`，融合权重逐位保持基线值，原零权重族不参与新增搜索；需要同时探索六类模型时，可预先选`uniform_fixed`等权。两者都不使用当前开发标签求权重。原价格专家1—5分的处理和纯数据开关继续保留。
6. 依据同折汇总开发MAPE/R²、训练门槛及尾部/最差折约束接纳候选。默认MAPE改善至少0.001个百分点；允许的最差折与P90误差恶化上限各2个百分点，始终相对原CV基线约束，避免逐轮漂移。
7. 默认全部开发记录重拟合并导出。原划分参数快照也保存，但其单划分分数与固定CV分开。固定外层留出价格不参与V3、CV选择、权重或重拟合。

固定CV消除了新增阶段挑容易划分及在评分标签上重拟合权重的路径。CV仍参与调参，V3起点也使用过开发标签，因此CV成绩不是独立测试精度；如需检验泛化，请在训练前配置`locked_holdout`或使用后续新成品。小样本无法保证任何算法都达到MAPE≤10%、R²≥0.9。

## 模式、预算与保存

新协议仍可选`goal_first`（固定CV总体指标）、`balanced`（总体及最差折权衡）、`robust`（增强折稳定约束，要求各折开发目标达标）。这些模式均在新增搜索中使用固定CV，而非最后才看复核。关闭旧`audit`开关不会取消新协议的必要CV。

`MODE_MENU.bat`的19—22项可切协议、固定权重方案、折数和重复次数，也可执行：

```bat
runtime\python38\python.exe tools\product_modes.py select --engine optuna_v5 --protocol fixed_cv --weight-policy baseline_fixed --cv-folds 4 --cv-repeats 1
```

`legacy_split`仅保留旧V5对照，仍有自适应权重和划分选择偏差，日志明确标记。V2/V3/V4保持可选。不同协议、权重方案及CV计划分别登记模型，旧高分模型不会冒充新协议产物。

| 入口 | 默认预算 |
| --- | --- |
| `APPLY_V5_1.bat` | V3设置沿用，新增60次实际成员fit |
| `APPLY_V5_1_QUICK.bat` | V3基线40轮，新增20次实际fit |
| `APPLY_V5_1_DEEP.bat` | V3基线300轮，总fit5000，1800秒软时间预算 |

固定4折时，一个新候选通常消耗4次fit，不是一次。预算不足以完成整组折时不开始该候选；相同参数命中缓存可减少实际fit。总预算另为快照和全量导出保留额度。首次必要CV基线必须完整完成，时间预算到达时不把部分折冒充完整CV。单次fit及可靠保存会完成后再停止。

`START.bat`只启动保存模型；`RETRAIN.bat`显式训练；`RESUME.bat`可继续同协议、数据和环境的检查点；`EXPORT.bat`导出当前模型及环境，不需要原输入表。提高新增fit预算后可以继续搜索，不必重跑已完成V3基线。

## 升级及日志

关闭旧程序，把PATCH解压覆盖旧包根目录，执行`APPLY_V5_1.bat`。升级备份配置，保留输入、数据库和旧模型，切到新的固定CV训练配置。补丁本身不训练；新协议尚无保存模型时，先`CHECK_INPUT.bat`再`RETRAIN.bat`。完整包可直接START虚拟演示。

价格输出目录新增：

| 文件 | 内容 |
| --- | --- |
| `training_verbose.log` | 阶段、拟合开始/结束、每折、每候选及停止原因；默认10秒心跳 |
| `training_events.jsonl` | 逐事件结构化明细，包括参数、行号、单模型/集成、优胜、权重及异常堆栈 |
| `enhancement_trials.jsonl` | 每个候选接纳/拒绝原因、固定折摘要、前后权重、实际fit和耗时 |
| `fixed_cv_plan.json` | 所有训练/验证源行号、覆盖次数和计划SHA256 |
| `fixed_cv_predictions.csv` | 每条折外预测、实际价格及误差，可重新计算主指标 |
| `fixed_cv_selection.json` | 原CV基线、当前CV优胜、冻结权重及停止原因 |
| `training_report.json` | 原V3单划分、同折CV基线、选中CV、全量训练及可选外层成绩 |

MAPE以10位有效数字、R²以12位有效数字记录，微小误差采用科学记数法，不再统一四舍五入成0.000%。数据解析、V3每成员/候选、必要CV、增强候选、导出、复载检查和异常均落盘；长拟合期间有心跳。

前台分别标注“V3原单划分（仅对照）”“同一固定CV基线”“固定CV开发（参与选参）”。开发达标与未达标试用草稿继续明确标记，不把旧单划分高分套到全量或CV上。

设计参考：scikit-learn的[StackingRegressor说明](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingRegressor.html)区分基础模型与融合层训练；[嵌套与非嵌套CV说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)说明选参后的评分偏差。实现使用项目内接口，没有引入新版sklearn依赖。
