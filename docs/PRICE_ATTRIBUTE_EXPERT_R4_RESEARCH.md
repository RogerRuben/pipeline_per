# R4补充研究与修改优先级

日期：2026-10-09。状态：方案补充与接口核验，业务训练实现尚未按本文件替换。继续采用“基准种子调参、固定参数探索种子、学习联合预测”的主流程。

本轮查阅价格相对误差、加权重采样、监督降维、高斯过程、模型库集成与特征稳定性的原始研究及官方文档，并检查现有源码。以下阈值、预算和组合是本项目的工程建议；引用的研究没有证明10条样本、40个属性必然达到某个精度。

**1. 先修正实际处理，再比较算法：优先级P0**

已用包内Python 3.8.10、sklearn 0.24.2直接复现：`services/price_service/ensemble_estimators.py`的`StableFoldImputer(strategy='mean')`仍走中位数分支。输入0、1、10、缺失时，均值模式实际返回1，正确均值为3.666667。后续须修正为真实均值/中位数，并把每折实际补全值写入报告。否则“搜索均值或中位数”只是配置不同，实际行为相同。

另外，`tools/product_pipeline.py`默认把`-1`设为全局缺失标记，`app/historical_onboarding.py`会同时匹配数字-1与字符串-1。对于真实允许-1的温度等属性，这会误删有效观测。新版建议默认只有空白为缺失，兼容旧标记通过显式配置启用，并支持按英文属性代号覆盖缺失规则。

输入处理还需输出实际进入价格训练的列、单位换算、原始类型与编码类型、每列缺失量、折内被过滤的列、重复业务组及未知类别。数字编码的控制方式、材料类型等不能只因单元格为数字就当作连续量；属性类型可在已有可选配置中声明，不能要求用户补齐一堆新表。

保留已修复的双行表头与控制台兼容处理。数据语义正确是后续模型比较的前提。

**2. 增加真正对齐MAPE的价格成员：优先级P1**

现有成员主要拟合平方误差或对数价格误差，MAPE/R²用于后续排名和融合。它们的训练目标并不完全相同。

对正价格，MAPE经验损失就是`mean(abs(y - p) / y)`，等价于样本权重为`1/y`的绝对误差回归。这一等价关系有[De Myttenaere等的原始研究](https://arxiv.org/abs/1605.02541)支持；拟合对数价格并不等于直接优化MAPE。

建议补充两个受控成员，而不是把全部模型改成同一损失：

- 专家加权的正则化相对绝对误差回归：在缩放后属性上最小化`mean(abs(y-Xβ-b)/y) + λ*sum(abs(β_j)/r_j)`，r来自价格评分。通过绝对值辅助变量转成线性规划，按训练折价格尺度做数值归一化。正则项不可省略，以免40个属性插值10条记录。
- 相对Huber回归：对`(p-y)/y`使用平滑稳健损失，加上专家引导的L2收缩，补充小误差区间的平滑性。这里是自定义相对残差，不把普通Huber随意加权说成精确相对Huber。

保留原价平方损失与对数价格候选，让R²和相对误差可以通过不同成员互补。价格接近零时，损失会敏感；不能悄悄加一个大分母后仍称为原MAPE。零价/无效价单独诊断；如增加权重截断，作为另一个有明确名称的候选，再用原MAPE审核。

SciPy 1.5.4的`linprog`有`interior-point`、`revised simplex`等旧版求解器；不能依赖该环境尚不提供的HiGHS。[版本文档](https://docs.scipy.org/doc/scipy-1.5.4/reference/generated/scipy.optimize.linprog.html)。实际还须检查求解状态、约束残差与无效价格输出。

**3. 用温和的随机样本权重让固定参数产生不同成员：优先级P1**

对固定参数、固定全量记录的确定性Ridge/Lasso，换数据划分种子不能自然得到不同的最终模型。普通bootstrap又会遗漏记录：从10条中有放回抽10次，独立记录的期望数为`10*(1-0.9**10)=6.5132`。在高维微样本下，直接大范围丢样本不宜作为默认。

建议借鉴[Rubin的Bayesian bootstrap](https://people.eecs.berkeley.edu/~jordan/sail/readings/rubin.pdf)，采用正的随机权重，并向等权收缩。一个拟议实现为：

`g_i ~ Exp(1)`

`v_i = (1-ρ) + ρ*n*g_i/sum(g)`

ρ=0为原始等权，ρ=1对应归一化指数权重；工程默认候选只取小扰动，例如0、0.15、0.30，必要时把0.50作为扩展。ρ小于1的向等权收缩是本项目改法，不把它宣称为原论文的精确后验。

参数冻结后，不同种子生成不同v，每个成员保留全部记录，再通过`sample_weight`拟合。每折按独立业务组生成权重，同组共享扰动；组内记录总权重策略须与基础训练一致。检查有效样本量`ESS=(sum(v))**2/sum(v**2)`，避免一个随机大权重主导结果。ρ、保留实例数和筛选规则只在开发训练部分选定；外层重新跑全部选择。

原始专家价格评分r是属性先验，v是样本扰动，`1/y`是MAPE损失权重，三者必须分别命名和记录。多个成员先在同一配置内平均，再参与配置之间的融合，防止16个近似模型占用16个独立融合自由度。

包内Ridge、Lasso、ElasticNet、Huber、KernelRidge、SVR的加权拟合接口均已通过小型输入验证。PLS没有直接的同类训练参数，不能强行传入；自定义专家树如支持样本权重，需要另外实现加权均值、损失与分裂增益。温和扰动只作为候选，与原始等权成员比较，不保证必然改善。

**4. 增加面向价格的PLS压缩：优先级P1**

PCA保留属性变化大的方向，可能丢掉变化小但与价格关联强的方向。PLS在训练时结合属性与价格，尤其适合作为高维、共线情况下的低维回归候选。[sklearn 0.24的原理说明](https://scikit-learn.org/0.24/modules/cross_decomposition.html)。

建议仅试1、2、3个潜变量，依据每折可用秩调整，并同时保留Ridge和PCA对照。PLS使用价格标签，因此补全、缩放、专家倍率和PLS全部在当前训练折内拟合。不能全量先做PLS再交叉验证。

专家倍率在外部缩放后施加，PLS设`scale=False`，避免内部重新标准化把属性倍率抵消。输出需适配其`(n,1)`预测形状，并把系数与载荷映射回原英文属性。包内已验证1—3分量单目标拟合可运行。是否优于其他成员须验证，不能用“监督降维”保证精度。

**5. 加入少参数的核岭或高斯过程：优先级P2，可选**

10条记录时，核矩阵规模很小，可以增加平滑非线性成员：专家加权RBF/Matérn核岭，或GPR。重点是控制全局长度尺度、噪声与收缩，不为40个属性分别学习40个自由长度尺度。

初版优先选择核岭；GPR作为标准模式扩展。折内专家倍率影响距离，核尺度依据当前训练部分设置。保留充分正则/噪声候选，避免近乎零噪声的插值被当作成功。

GPR内核默认会在拟合时继续优化参数，需按阶段明确控制：基准阶段允许内核估计或外部小范围搜索，种子固定参数阶段须使用`optimizer=None`或冻结相应参数，才能符合“固定超参数”的含义。[sklearn 0.24 GPR接口](https://scikit-learn.org/0.24/modules/generated/sklearn.gaussian_process.GaussianProcessRegressor.html)。

核模型在历史覆盖外可能回到先验均值，不能因此自动视为可信报价；GPR返回的标准差依赖建模假设，也不等于在10条业务样本上验证过的95%覆盖率。包内固定内核GPR已完成拟合/预测接口核验，原生导出与服务适配仍待实现。

**6. 专家评分加入容错与分组解释：优先级P1，分组参数扩展为P2**

1—5分是有序的重要性判断，不足以精确规定每个系数的方差或贡献。默认保留全局先验强度调节，专家原始评分始终保存。

对多位专家，保留各自评分、中位数和分歧，增加“共识先验”和少量单专家先验对照；不为所有专家组合展开无限搜索。未评分继续使用中性倍率并保留来源标记，不能说专家实际打了3分。

相互关联的规格可以按用户已有属性分组或明确声明的价格属性组，汇总贡献和跨折稳定性。重复/近重复属性先提示，不依据10条样本的偶然相关性自动认定物理耦合。这样可以解释“某组整体影响稳定，但组内单个系数不稳定”。

可选扩展是在全局强度上增加少量组级修正，最多2—3个组，配合收缩；不能对40个属性逐个学独立倍率。若给专家评分作内部扰动，需要声明允许区间/分歧依据和种子规则，不改写用户原始表格。对小样本优先用评分关闭、温和、完整三个对照，不默认追加高维评分搜索。

[稳定性选择研究](https://arxiv.org/abs/0809.2932)启发我们检查变量在样本扰动下是否反复出现，但本项目的选择频率和符号稳定率仅作诊断。10条样本下不能宣称获得论文条件下的错误发现控制，更不能把频率低的属性一律硬删除。

**7. 融合选择先看残差互补，并限制权重自由度：优先级P1**

开发阶段保存每条记录、每个候选的折外相对残差`e_im=(p_im-y_i)/y_i`。对新候选，先评估其加入现有组合后的整体MAPE/R²变化，残差相关性只辅助判断；“两个模型相关性低”不等于一定改善预测。

先在同一配置的种子/扰动成员内平均，再做模型族内部筛选或平均，最后学习少量不同配置/模型族的非负份额。微样本初始最多2—4个真正不同配置，若增加成员，需要实测互补增益。避免几十个近重复成员由9条开发记录各自拟合份额。

新增“贪心加入成员后再拟合少量权重”的候选，与已有正则融合、等权和单模型比较；整个过程放进外层。使用折外预测缓存，比较组合无需再次训练各成员。直接优化最终业务指标的模型库选择可参考[Caruana等，ICML 2004](https://doi.org/10.1145/1015330.1015432)；原论文并不是10×40价格数据的精度证明。

权重向简单参考收缩，并检查删除一个业务组后权重和预测变化。无需在10条数据上估计并求逆一个大规模、病态的残差协方差矩阵。专家价格评分仍作用于成员训练，不转换为这些模型族份额。

**8. 增加一个受控的报价校准系数：优先级P2，可选**

若折外残差表现为系统性低估或高估，可加入一个向1收缩的全局乘数a：最终价格为`a * 集成价格`。默认保持a=1；候选校准只能用训练部分折外预测拟合，并重新经过外层审核，不能用审核/外部真实价格调整。

固定正的预测p时，最小化`sum(abs(y-a*p)/y)`等价于对比值`y/p`求权重`p/y`的加权中位数。这是由MAPE表达式直接推导的工程实现，不是新增专家成本系数。校准系数可设置预先固定的范围并向1收缩，再检查R²是否受损。

只有一个自由校准参数，避免再学40属性的高维残差去掩盖原模型不足。解释中分别显示原集成金额、校准乘数与最终金额。若某段价格范围的偏差不同，10条数据下先报告，不默认学习按方案动态改变权重的复杂网络。

**9. 搜索预算与实施顺序**

必做顺序为：P0修复真实处理和价格评分路由；P1增加相对损失成员、温和样本权重扰动、PLS与有约束的互补融合。P2核模型、组级先验修正和单参数校准按预算开启。

保留初次一个基准种子调参的设计。种子阶段冻结超参数，允许估计器随机性和明确的样本权重扰动；专家强度、ρ等仍属于参数阶段决定的设置，不能在“参数已固定”后偷偷继续搜索它们。

每个外层训练部分独立重跑同一流程。缓存可进一步细化到折内补全/缩放后的矩阵和固定特征表示的核距离，但缓存键必须包含样本边界、字段、评分、变换选项和版本；PLS等使用目标的变换必须包含当前训练标签。任何信息不能从外层审核部分流入缓存。

模式设“快速”“标准”“深度”，按优先级分配配置预算，新增候选占用预算而不无限追加。种子探索上限分别为64、500、5000次，和最终平均成员数分开；5000是深度预算上限，不是每个模型必做5000次拟合的证明。深度模式须独立设置时间/拟合预算，不能沿用快速预算又声称完成5000次。完成的候选必须有同口径完整预测；预算不足时交付已完成的试用模型与明确的审核完成状态，不把未完成检查填成通过。

2026-10-12新增划分覆盖检查：10条独立记录按8:2划分最多45个不同留出集合，按两个各5条的层分别留1条则为25个。实际尝试5000个种子确认这两个集合数，未拟合任何价格模型；结果见`outputs/reference_price_automl_20261009/seed_partition_coverage_20261012.json`。划分集合可去重枚举，训练随机性与样本权重扰动另计。小样本下不把重复切分或仅训练顺序差异当作新的独立验证证据。

验收增加有针对性的对照：损失切换、扰动关闭/开启、PCA/PLS、核模型关闭/开启、相同族成员先平均/各自学权重、评分正确/错误/不完整、校准关闭/开启。每个对照使用预先声明的数据与协议，记录所有运行；开发改进与独立审核改进分开显示。

本轮接口核验在当前主机使用包内运行时完成，确认Python 3.8.10、sklearn 0.24.2、NumPy 1.19.5、SciPy 1.5.4的关键接口可用。它不是Win7实机测试，也不是上述方法的真实业务精度测试。仍须按照主方案完成实现、原生导出/HTTP一致性及真实表验证。
